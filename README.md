# Python Tic-Tac-Toe
A simple yet humorous tic-tac-toe game built in Python as a learning project.

## Features
- two player gameplay
- board display after each move
- win / draw detection
- fun instructions

## Installation


## How to play
1. The game is played on a 3x3 grid
2. Players enter their names. The game will automatically decide who goes first. The first player use "X" as their mark, second player use "O"
3. Whoever get 3 of their mark in a row wins.
4. If the board fills up before anyone wins, it's a draw.
5. Players have the option to replay.
